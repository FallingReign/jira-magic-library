# JML 3.0.0 release verification

## Fixes

- F1: Scalar time tracking becomes an original-estimate object. Quoted and unquoted YAML inputs behave consistently.
- F2: Creation omits blank optional fields in every input format and validates required fields using Jira metadata.
- F3: Literal description blocks preserve text without double escaping, including quoted wrappers.
- F4: Standard JSON escaping is preserved. Legacy quote repair is explicitly enabled and runs only after normal parsing fails.
- F5: Validation cannot enter submission paths. Creation and preview share field preparation; preview errors cannot be mistaken for usable payloads.
- F6: Regression coverage replaces tests for the old text rewriting, adds previously missing coverage, and verifies the polling shutdown fix. Existing coverage thresholds remain unchanged.

## Verification

Local checks use Node 24 on Windows. The complete unit suite, coverage thresholds, ESLint, TypeScript build/type check, generated API documentation, and packaged-import check are release gates. Unit tests: **86 suites passed, 2,418 tests passed, 3 pre-existing skipped tests**. Coverage: **98.14% statements, 95.05% branches, 96.35% functions, 98.38% lines**. ESLint passed with 0 errors and 29 warnings. TypeScript and API documentation builds passed; documentation warnings remain.

Live Jira Server/Data Center checks on 2026-09-04 verified all four cases below. Each case compared preview with validation, created an issue, and read its fields back from Jira. All saved descriptions matched exactly, all original estimates were 7,200 seconds, and Sprint was absent.

| Case | Read-back result |
| --- | --- |
| Unquoted YAML estimate | Passed |
| Quoted YAML estimate | Passed |
| Nested YAML estimate | Passed |
| JSON estimate, blank Sprint and quoted literal block | Passed |

The test account does not have permission to delete issues in the configured test project. These four test issues remain for an administrator to remove; their keys are retained in the local acceptance log and the user handoff. The first deletion returned HTTP 403; no permission escalation was attempted. The live acceptance assertions passed before this cleanup failure. Jira Cloud has mocked coverage; it was not tested against a live Cloud tenant.

The live harness is `scripts/release-input-smoke.mjs`. It uses `.env.test`, the authenticated account as Reporter, and a separate temporary Redis on port 16379 (override with `JML_SMOKE_REDIS_PORT`). Run with `--live` only when another set of temporary issues is wanted.

The packed 3.0.0 tarball was installed into a separate consumer folder. Its compiled package passed import, exact-description, scalar-estimate and blank-Sprint checks against the dependency versions selected by that fresh installation.

## SHGJiraTools

The existing application passed 632 tests during investigation. Its deployed library version was verified as 2.2.0. This release changes the library only. Follow [the migration and handoff guide](../guides/upgrading-to-3.md#shgjiratools-handoff) for the application update.

The quoted-YAML error telling the user to remove quotes was not reproduced as a separate message; the exact original template was not supplied. Both quote styles are covered by unit tests and live creation checks in this release.
